# Wizard Scorepad

Interaktiver Punktezähler für das Kartenspiel Wizard mit Gewinnprognose.

## Features
- Punktezähler für 3–6 Spieler
- Rundenübersicht mit Vorhersage vs. tatsächliche Stiche
- Gewinnprognose (Kristallkugel-Modul)
- Punkteverlauf als Liniendiagramm
- Verbotene-Summe-Regel (ein-/ausschaltbar)
- Spielstand-Speicherung per URL-Hash

## Deployment

Deployed via Cloudflare Pages. Keine Build-Schritte nötig — `index.html` läuft direkt im Browser.
